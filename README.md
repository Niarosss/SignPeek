# SignPeek 👁️✅

**SignPeek** — це професійний веб-інструмент для миттєвого перегляду підписаних документів та розпакування криптографічних контейнерів прямо у вашому браузері.

Проект створений як швидка та безпечна альтернатива державним онлайн-сервісам. Головна перевага — **повна приватність**. Всі операції виконуються на стороні клієнта, файли не завантажуються на жоден сервер.

🚀 **Жива демо-версія:** [signpeek.niaros.dev](https://signpeek.niaros.dev)

---

## ✨ Ключові особливості

### 🔐 Криптографія та Електронний Підпис
- **Підтримка форматів:** Робота з бінарними підписами **CAdES** (`.p7s`, `.p7m`) та XML-підписами **XAdES** (`signatures.xml`).
- **Аналіз сертифікатів:** Вилучення детальних даних про підписувача (ПІБ), організацію, АЦСК та термін дії сертифіката прямо з ASN.1 структури.
- **Джерело vs Вміст:** Візуальне розділення контейнера-підпису та вкладеного документа в ієрархічному дереві.

### 📁 Робота з контейнерами та архівами
- **Рекурсивна розпаковка:** Підтримка вкладених контейнерів ("матрьошок") — наприклад, `.asice` всередині `.zip`.
- **ASiC-E / ASiC-S:** Повна сумісність з українськими та європейськими стандартами підписаних архівів.
- **Розумний експорт:** Можливість вилучити окремий файл або завантажити весь вміст контейнера одним новим архівом (.zip).

### 📄 Універсальний в'ювер (Engines)
- **Документи:** Прецизійний рендеринг **PDF**, **Word** (`.docx`, `.doc`) та **Excel** (`.xlsx`, `.xls`, `.csv`).
- **Медіа:** Перегляд зображень, включаючи **HEIC** (Apple) та професійні скани **TIFF**.
- **Інструменти:** Плавний зум, панорамування, поворот сторінок та ефект "marquee" для довгих назв файлів.

## 🛠 Технологічний стек

- **Core:** [React 19](https://reactjs.org/) + [Vite](https://vitejs.dev/).
- **Styling:** [Tailwind CSS 4.3.3](https://tailwindcss.com/) (Fluid Design, адаптивність).
- **Cryptography:** [PKI.js](https://pkijs.org/), [ASN1.js](https://github.com/PeculiarVentures/asn1js).
- **File Processing:** [JSZip](https://stuk.github.io/jszip/), [File-type](https://github.com/sindresorhus/file-type).
- **Viewers:** [PDF.js](https://mozilla.github.io/pdf.js/), [docx-preview](https://github.com/VolodymyrBaydalka/docx-preview), [SheetJS](https://sheetjs.com/).
- **Icons:** [Phosphor Icons](https://phosphoricons.com/).

## 🛡 Приватність (No-Server Architecture)

SignPeek побудований на принципі **Local Data Processing**:
1. **Жодного Backend-у:** Додаток не має серверної частини для обробки файлів.
2. **Пам'ять браузера:** Розпакування та рендеринг відбуваються виключно в оперативній пам'яті (RAM) вашого пристрою.
3. **Security:** Виключена можливість перехоплення документів на шляху до сервера, оскільки передачі даних не існує.

## 📦 Швидкий старт (Локально)

1. Клонуйте репозиторій:
   ```Bash
   git clone https://github.com/Niarosss/SignPeek.git
   ```
2. Перейдіть у папку проекту:
    ```Bash
    cd SignPeek
    ```
3. Встановіть залежності (рекомендовано pnpm):
    ```Bash
    pnpm install
    ```
4. Запустіть сервер розробки:
    ```Bash
    pnpm dev
    ```

## 📐 Структура проекту

```Text
/src
  /components
    /layout       # Каркас додатка: Header, Sidebar, Footer
    /viewer       # Логіка в'ювера: Host, Toolbar, WelcomeScreen
    /ui           # Атомарні компоненти: Кнопки, Модалки
    /engines      # Двигуни рендерингу (PDF, Docx, Image, Xlsx)
  /hooks          # Кастомні хуки (useFiles для керування станом)
  /utils          # Утиліти: CryptoParser (PKI.js) та FileProcessor (JSZip)
```

## 🛡️ Безпека та Приватність

- SignPeek реалізує концепцію "Zero-Server Tracking":
- Файли обробляються виключно в оперативній пам'яті вашого браузера.
- Жоден байт ваших документів не передається на сторонні сервери.
- Вся криптографічна перевірка виконується локально через Web Crypto API.
